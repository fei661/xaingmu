# QQ风格即时通讯软件

基于Qt框架开发的即时通讯软件，实现类似QQ的核心功能。

## 功能特性

- **登录注册**：账号注册、登录验证、服务协议勾选
- **好友管理**：添加好友、删除好友、在线状态显示（绿色[在线]/灰色[离线]）
- **即时聊天**：文本消息、表情消息、文件传输
- **辅助功能**：天气查询、日期时间显示、HTTP图片查看

## 技术栈

- **框架**：Qt 5.x
- **语言**：C++
- **数据库**：SQLite
- **网络**：TCP/IP协议

## 快速开始

### 环境要求

- Windows 10/11
- Qt Creator 4.x+
- Qt 5.15.x 或 Qt 6.x

### 编译运行

1. 使用Qt Creator打开项目文件 `Login.pro`
2. 配置构建套件（Desktop Qt 5.x MSVC 2019 64bit）
3. 点击构建按钮生成可执行文件
4. 运行生成的 `Login.exe`

### 测试方法

1. 启动第一个实例，注册并登录账号A
2. 启动第二个实例，注册并登录账号B
3. 在账号A中添加账号B为好友
4. 在账号B中添加账号A为好友
5. 双击好友进行聊天测试

## 架构设计

### 点对点通信

项目采用点对点（P2P）架构，每个用户程序同时作为客户端和服务端：

- **服务端**：`QTcpServer` 对象，监听端口（8888-8987），接收连接
- **客户端**：`QTcpSocket` 对象，发起连接，发送消息

### 数据库设计

**user表**：存储用户信息
| 字段 | 类型 | 说明 |
|------|------|------|
| username | TEXT | 用户名（主键） |
| name | TEXT | 用户昵称 |
| ico | TEXT | 头像文件名 |
| password | TEXT | MD5加密密码 |
| ip | TEXT | IP:端口号 |

**friend表**：存储好友关系
| 字段 | 类型 | 说明 |
|------|------|------|
| username | TEXT | 当前用户名 |
| friendname | TEXT | 好友用户名 |
| friendip | TEXT | 好友IP地址 |

## 使用说明

### 登录注册

1. 打开程序，显示登录界面
2. 点击"注册"按钮，进入注册界面
3. 输入用户名、密码，选择头像，点击注册
4. 返回登录界面，输入账号密码，勾选服务协议，点击登录

### 好友管理

1. 在搜索框中输入好友用户名
2. 点击"添加好友"按钮添加好友
3. 选中好友，点击"删除好友"按钮删除好友
4. 好友列表显示在线状态（绿色在线/灰色离线）

### 聊天功能

1. 点击左侧导航栏聊天图标（10.png）打开好友列表
2. 双击好友打开聊天窗口
3. 输入消息，点击发送按钮发送文本消息
4. 点击表情按钮选择表情发送
5. 点击文件按钮选择文件发送

### 辅助功能

- **天气查询**：点击天气图标（8.png），输入城市名查询天气
- **日期时间**：点击时间图标（9.png），查看当前日期时间
- **HTTP图片**：点击图片图标（22.png），查看HTTP图片
- **返回登录**：点击底部图标（16.png），返回登录界面

## 通信流程

```
用户登录
    ↓
启动TCP服务端（动态分配端口）
    ↓
更新数据库IP字段
    ↓
加载好友列表
    ↓
定时刷新好友状态（每3秒）
    ↓
查询好友IP，建立TCP连接
    ↓
收发消息
```

## 消息协议

| 消息类型 | 结束标志 | 说明 |
|----------|----------|------|
| 文本消息 | `\nMSG_END\n` | 普通文字消息 |
| 表情消息 | `\nMSG_END\n` | HTML格式，含Base64图片 |
| 文件消息 | `\nFILE_END\n` | 文件数据Base64编码 |
